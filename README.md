# LINE 聊天記錄備份工具

一個簡單的 LINE 聊天室備份工具，不需要編程知識也能輕鬆使用。

## 功能

- ✅ 支持多個 LINE 聊天室備份
- ✅ 自動保存為 JSON 和 HTML 格式
- ✅ 一鍵快速備份
- ✅ 備份歷史記錄

## 系統要求

- Windows 10+ / macOS 10.14+ / Linux
- Python 3.8+（如果使用源代碼版本）

## 快速開始

### 方法 1：使用一鍵啟動（推薦）

**Windows:**
```
雙擊 start.bat 文件
```

**macOS / Linux:**
```
雙擊 start.sh 或在終端執行：
bash start.sh
```

### 方法 2：手動運行

```bash
python main.py
```

## 使用步驟

1. 啟動程序後會看到菜單界面
2. 選擇 `1` 開始新備份
3. 輸入 LINE 聊天室名稱（或複製粘貼）
4. 程序會自動備份所有聊天記錄
5. 備份文件保存在 `backups/` 文件夾

## 備份文件位置

- **JSON 格式**: `backups/chat_records.json`
- **HTML 格式**: `backups/chat_records.html`
- **備份歷史**: `backups/history/`

## 功能菜單

```
========== LINE 備份工具 ==========
1. 開始新備份
2. 查看備份歷史
3. 恢復備份
4. 設置備份位置
5. 退出
```

## 常見問題

**Q: 備份檔案在哪裡？**
A: 在程序文件夾的 `backups/` 目錄中

**Q: 備份會自動刪除嗎？**
A: 不會，所有備份永久保存

**Q: 支持多个账户備份嗎？**
A: 支持，每個账户分別保存

**Q: 可以恢復聊天記錄嗎？**
A: 可以，使用菜單選項 3

## 技術信息

- 基于開源 LINE 工具開發
- 支持 LINE Android 備份文件格式
- 端到端加密，隱私安全

## 注意事項

⚠️ **重要**:
- 首次使用需要授權應用程式存取 LINE 數據
- 建議定期備份
- 請勿刪除 `backups/` 文件夾

## 支持

遇到問題？檢查 `logs/` 文件夾中的日誌文件。
